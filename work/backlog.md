# Ticket ledger

Local ledger for `factory-manager`. The queue itself is the GitHub project board
"Learning Companion" (Todo column, top to bottom). One line per issue picked up:
`- [~] #<issue> <ticket-id>: <title>` while in flight, `[x]` when done.
`factory-manager` owns these lines — don't edit them by hand.

- [~] #1 project-scaffold: Project scaffolding: runnable Django project
